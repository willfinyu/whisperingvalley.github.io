# Hemal Gate

![Gate architecture frame](./data/header.png)

The Hemal Gate is an ancient transit mechanism that opens through patterned blood signatures.

## Core Concept

- Not teleportation, but folded displacement
- Requires paired anchors
- Distorts sound before light

The gate is both a plot device and a visual motif for chapter transitions.
